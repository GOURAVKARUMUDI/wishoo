# Friendship Surprise ❤️

A premium interactive mobile-first web application for sharing a beautiful Friendship Day surprise.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- 🎭 12 interactive screens with smooth transitions
- 💌 Animated envelope opening
- ✍️ Typewriter letter animation
- 📸 Photo memories carousel
- 📅 Animated memory timeline
- 🎈 Balloon popping game
- 🎫 Scratch card reveal
- 💬 Swipeable compliment cards
- 🧠 Interactive friendship quiz
- 🌧️ Emoji rain celebration
- 🎵 Floating music player
- 🎉 Grand finale celebration

## Tech Stack

- React 19
- Vite
- Framer Motion
- React Confetti
- Lottie React
- React Icons
- CSS Modules

## Customization

- Add your photos to `src/assets/photos/`
- Add your music to `src/assets/music/`
- Edit letter content in `src/utils/constants.js`
- Edit timeline memories in `src/utils/constants.js`
- Edit quiz questions in `src/utils/constants.js`
